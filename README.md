## How it works

`main.py` (Python 3, standard library only) writes the entry line to `$MAKEFUN_OUTPUT_DIR/entry.txt` with a plain file write — no trailing newline, so the character count is exact.

```bash
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
